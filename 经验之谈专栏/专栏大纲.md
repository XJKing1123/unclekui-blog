# Flutter【经验之谈】专栏大纲

## 专栏定位

面向已经接触 Flutter、正在参与实际项目的开发者。每篇只解决一个常见问题，用尽量通俗的语言讲清现象、原因、处理方式和适用边界。

文章不追求完整覆盖某个技术体系，重点回答开发现场最常出现的三个问题：为什么会这样、现在怎么处理、以后如何避免。

## 选题原则

- 问题必须来自日常开发、联调、测试、上线或维护过程。
- 标题尽量包含现象、冲突或明确结论，避免宽泛的“全面解析”。
- 单篇建议约 1200～2500 个中文字符，复杂问题拆成系列。
- 优先写高频、容易误判、能形成稳定解决思路的问题。
- 版本相关结论必须标明 Flutter、Dart、平台或插件的适用范围。

## 第一辑：页面为什么没有按预期更新

1. `setState` 调用了，页面为什么没变化？
2. `setState` 应该包住异步请求吗？
3. 接口回来了，为什么旧数据覆盖了新数据？
4. `ListView` 中一行数据变了，为什么整页都在重建？
5. `Key` 不是越多越好：什么时候真的需要它？
6. 弹窗关闭后更新页面，为什么经常遇到 `mounted` 问题？

## 第二辑：生命周期与资源释放

1. 页面销毁了，异步任务为什么还在继续？
2. `TextEditingController` 不释放，真的会出问题吗？
3. `StreamSubscription` 忘记取消会发生什么？
4. `initState`、`didChangeDependencies` 到底该把初始化写在哪里？
5. App 切到后台后，哪些任务不能想当然地继续运行？
6. 页面反复进入退出后越来越卡，先检查哪些资源？

## 第三辑：异步、网络与数据竞态

1. 连点两次搜索，怎样避免后返回的旧请求覆盖结果？
2. `Future.wait` 中一个请求失败，其他请求会怎样？
3. 网络重试不是多调几次：哪些请求可以安全重试？
4. 下拉刷新与上拉加载同时发生，状态应该怎么管？
5. Token 过期后多个接口同时刷新，如何避免重复刷新？
6. 页面显示“加载中”很简单，为什么加载状态仍然容易写乱？

## 第四辑：布局与交互中的高频问题

1. `Row` 为什么会溢出？先弄清约束从哪里来
2. `Expanded` 和 `Flexible`，不要再凭感觉选
3. 键盘弹出后页面溢出，应该改布局还是改滚动？
4. `ListView` 套 `ListView`，为什么经常出现高度问题？
5. 点击区域太小，不一定是按钮尺寸的问题
6. 输入框焦点乱跳，FocusNode 应该由谁管理？

## 第五辑：列表、图片与滚动体验

1. 长列表卡顿，先别急着上缓存
2. 图片列表闪烁，问题可能不在图片组件
3. 分页列表为什么会重复数据或漏数据？
4. 滚动位置丢失，`PageStorageKey` 能解决哪些问题？
5. 列表中使用 `shrinkWrap`，方便背后的代价是什么？
6. 大图加载导致内存上涨，应该先观察哪些指标？

## 第六辑：性能问题怎么判断

1. 页面“感觉卡”，第一步应该测什么？
2. Rebuild 多就一定卡吗？
3. Repaint 和 Rebuild 不是一回事
4. 60 Hz 与 120 Hz 屏幕，帧预算有什么不同？
5. Debug 模式很卡，能不能据此判断线上性能？
6. `const` 能优化性能，但别把它当万能答案
7. CPU、GPU、内存问题，如何先做方向判断？

## 第七辑：状态管理与代码边界

1. 这个状态到底该放页面里，还是放全局？
2. 状态管理框架解决不了混乱的状态设计
3. 一个页面多个加载状态，怎样避免互相覆盖？
4. ViewModel 越写越大，通常是哪里出了问题？
5. Repository 应该返回异常、结果对象还是空数据？
6. Provider、Riverpod、BLoC 怎么选：先看团队和生命周期

## 第八辑：工程协作与上线排障

1. “我这里没问题”：如何留下可用的 Flutter 问题现场？
2. 线上崩溃只有堆栈，怎样还原用户操作路径？
3. 插件升级前，应该检查哪些兼容性风险？
4. Android 正常、iOS 异常，排查时先找哪些平台差异？
5. 本地能跑、CI 失败，常见差异来自哪里？
6. 发版后指标变差，怎样判断是否由本次改动引起？
7. 技术债不是“以后再改”：怎样记录才真的有人处理？

## 单篇文章约定

每篇优先采用以下结构，并根据主题删减：

1. 问题场景与核心结论
2. 问题是怎么出现的
3. 真正的原因
4. 应该怎么处理
5. 容易踩的坑
6. 最后记住这几点
7. 问答复盘（5～7 组）
